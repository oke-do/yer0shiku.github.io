# Лизинг, аутстаффинг и аутсорсинг персонала: опыт и проблемы использования

Автор: Болотин Роман Алексеевич, группа М-34.
Стек: Vite + React + TypeScript + Tailwind 3 + Lenis + lucide-react.

    npm install
    npm run dev       # затем открыть http://localhost:5173/ (окно терминала не закрывать)
    npm run build     # tsc + vite build, результат в dist/

## Структура `src/components`
- `HeadHero` — первый экран: автор, видео с облётом камеры вокруг головы (`public/head.mp4`) крутится по скроллу, появляются тема и введение
- `ScrollyHero` — схема «Заказчик — Провайдер — Работники», меняется по скроллу (аутсорсинг → аутстаффинг → лизинг)
- `Brief`, `Compare` — короткий ответ и таблица отличий
- `Scenarios` — скроллителлинг: три ситуации (сезонный пик, непрофильные процессы, лимит штата)
- `CostStory` — скроллителлинг: из чего складывается стоимость сотрудника
- `Carousel` — горизонтальная карусель карточек с фото (`public/img/01–09.jpg`), поочерёдное появление
- `Law`, `World`, `Practice`, `Problems`, `Contractor`, `Picker` — право, мировой опыт, практика, проблемы, чек-лист, подбор модели
- `Sources` — использованные источники; `Footer` — подвал
- Для `prefers-reduced-motion` у всех анимированных блоков есть статичные варианты.

Тексты схем и сцен: `src/data.ts`, `Scenarios.tsx`, `CostStory.tsx`. Рекламные фрагменты из исходных материалов в сайт не включены.
